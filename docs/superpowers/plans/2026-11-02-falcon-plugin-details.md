# Falcon plugin detail and management

Implement the supplied Codex plugin-store pattern in the existing local worktree. Codex establishes the pattern; apply it to every supported integration, retaining each provider’s real configuration flow.

- Detail: breadcrumb, provider mark/title, restrained action group, a product preview with three QA examples, description, MCP connection and factual information rows. Match the supplied proportions, neutral palette and existing OpenAI Sans/SDK icons.
- Install: register the integration inside Falcon, with a brief Installing state, then Manage. Do not create or download files, ZIPs, or host installations. Availability in Falcon does not claim OAuth completion or activate a company seat.
- Manage: Settings → Plugins → Codex, with grouped link rows, inline connection setup, actual tenant URL/scopes, own grants, guide and server-authorized company controls. Ordinary Plugins navigation returns the list.
- Settings list: show available integrations and configured states. Existing connections may be disabled through their real API/CAS; unconfigured entries lead to Manage. Do not fake an enabled integration or bypass managed-session/company/project rights.
- Keep the existing OAuth consent, quota, concurrency, idempotency and cancellation behavior. Do not change backend contracts or authentication.
- Add a development-only synthetic managed workspace preview instead of relaxing production access gates. Preserve the previous local suite fixtures.
- Check installation state transitions and absence of file downloads, navigation history, unavailable/quota/error states, TypeScript and architecture. Review desktop/narrow browser layouts and download/manage/list flows. No production publication in this iteration.

User correction: replace native advanced disclosure markers with clean code presentation; put icon-only clipboard actions in the top-right of each code frame; round both MCP row hover surfaces.

Final scope: Codex, YouTrack, Jira, Linear, Trello, GitHub, Slack, Confluence and Swagger share detail → internal registration → Settings manager. GitLab/Jenkins/TeamCity remain planned. Installing stays visible at least 650ms and crossfades into Manage over 200ms. Connections use 16px insets; code frames have top-right clipboard icons.

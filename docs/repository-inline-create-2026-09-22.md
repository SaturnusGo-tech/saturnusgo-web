# Создание из дерева репозитория

Статус: локальная проверка, ветка `feature/repository-inline-create`.

## Поведение

- При наведении или клавиатурном фокусе на папке под её строкой появляется «Добавить подпапку». Родительские строки не раскрывают свои действия при наведении на потомка.
- Действие открывает поле имени на месте. Enter или круглая галочка сохраняют; Escape или крестик отменяют. Уход курсора не закрывает ввод.
- Пока запрос выполняется, повторное сохранение блокируется. При ошибке введённое имя сохраняется. Новая папка выбирается и остаётся видимой даже при активном поиске.
- У тест-кейса появляется небольшой плюс справа внутри строки. Дополнительной строки, изменения высоты или второго фона при наведении нет. Место под плюс зарезервировано заранее.
- Плюс открывает существующий редактор нового кейса в папке строки, независимо от ранее выбранной папки. Для кейса без папки передаётся корень `/`.
- Создание не предлагается в архиве, в режиме выбора или без права управления. На сенсорных устройствах действия доступны без наведения; reduced-motion отключает переходы.

## Реализация

`RepositoryFolders` передаёт необязательную возможность создания в ветви и строки. Другие потребители общего дерева её не получают. Создание папки использует существующий `FolderResource.create`; авторизация, идемпотентность и проверка контекста остаются в существующем слое команд. Сервер и API не менялись.

## Проверка

- `npm run typecheck`, `npm run architecture:tms`, `npm run build`: успешно.
- `npm run test:tms-organization`: 212 + 3 успешных теста, включая 9 новых проверок родительского контекста, прав, архива, фильтра, повторного сохранения, ошибки и отмены.
- Локальный стенд использует реальные компоненты репозитория и темы, управляемый тестовый ресурс папок и замену редактора, показывающую переданный путь. Продакшен-данные не изменяются.
- В браузере проверены светлая и тёмная темы, вложенные папки, Enter, галочка, Escape и путь нового кейса в подпапке и корне.
- При наведении в папке с 200 кейсами координаты и высота всех строк остаются неизменными.
- Снимки и стенд: `output/falcon-inline-create-20260922/` в родительском рабочем каталоге.
